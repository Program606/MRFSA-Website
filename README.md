# MRFSA Intro Site

A fast, accessible, single-page site for the Mount Royal Filipino Student Association.

## How to run
Open `index.html` in your browser. No build step required (Tailwind via CDN).

## Edit events
Update `events.json`. Each item supports `date`, `title`, `location`, `image`, and `description`.

## Assets
Images are used exactly as provided and stored in `assets/`:
- hero.png (hero background)
- events.png (events banner/thumbs)
- team.png (team banner)

## Tech
- HTML + Tailwind CDN + minimal JS
- WCAG-conscious semantics, skip link, visible focus states
